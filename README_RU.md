# FixTok — чистая пересборка с нуля

Это новый минимальный Android-проект, который заменяет старый код. Он не копирует старую реализацию.

## Что есть
- Android TV / Google TV launcher и обычный Android launcher;
- TikTok WebView;
- кнопки «Главная», «Войти», «Обновить», «Настройки»;
- управление пультом: обычная навигация WebView, MENU открывает настройки, BACK возвращает назад;
- настройка масштаба текста;
- подтверждение выхода с очисткой cookies;
- сообщения о загрузке и ошибках;
- базовые ограничения безопасности: только HTTPS/HTTP и навигация по домену TikTok, блокировка внешних сайтов и file access.

## Важно
- Это стартовая чистая версия, не гарантированная замена всех функций прежнего FixTok.
- TikTok может менять сайт, блокировать WebView или требовать более новый WebView/Chrome.
- Качество навигации по видео зависит от версии Android System WebView и прошивки телевизора.
- Кнопка выхода удаляет все cookies WebView, поэтому удалятся и другие сохранённые веб-входы.
- APK не включён; проект нужно собрать через Android Studio или GitHub Actions.
- Сборка в этой среде не запускалась, поэтому сначала проверь сборку и тестируй на отдельном устройстве.

## Сборка
Открой папку проекта в Android Studio с JDK 17 и выполни `assembleDebug`.
На GitHub Actions workflow в `.github/workflows/build.yml` запускает сборку при push или вручную.
